## ⚠️ Automação de compra

O app oferece uma automação opcional via **Acessibilidade do Android** que adiciona os produtos ao carrinho do Mercado Livre e leva até a tela de pagamento. Ela só funciona se você ativar manualmente nas configurações do sistema.

**Aviso:** essa automação pode violar os Termos de Uso do Mercado Livre e pode ser rejeitada pela Google Play (a API de Acessibilidade é destinada a ajudar pessoas com deficiência). Use por sua conta e risco. O fluxo manual continua disponível como fallback.
